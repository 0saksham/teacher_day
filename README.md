# 🎓 Happy Teacher's Day, Ms. Manika Manwal! 💻✨

An interactive, responsive Computer Science Teacher's Day tribute portal and CS Memory Lab.

## 🌟 Features
- **Cinematic Holographic Intro:** Embedded video greeting (`Hello Mam.mp4`).
- **Interactive CS Mentorship Story:** Multi-scene experience covering classroom pillars, personal heartfelt letter, and honorary certification.
- **CS Memory Lab & Playground (`additional.html`):** Interactive module compiler, CS memory matrix, mascot interactions, and audio controls.
- **Offline Soundtrack:** Built-in audio playback (`music.mp3`) with interactive equalizer controls.
- **Mobile-Optimized:** Fluid layouts, viewport-locked design, and touch-friendly navigation across all devices.

## 🚀 Live Access
Open `index.html` or `teachers-day-surprise.html` in any modern web browser.
